# 验证范围

本版已完成：

- 163 项 Python 测试，39 项需要显式提供隔离 MySQL 的集成测试默认跳过，其余通过。
- 控制器、看板两个 Docker 镜像构建成功。
- 默认及 database、usb、phone profile 的 Compose 配置解析通过。
- Compose 目录边界、只读数据库账号分离、启动前检查依赖和数据库回环端口检查通过。
- 无网络、只读临时假照片的容器测试：正常目录接受、源目标重叠拒绝、错误文件系统类型拒绝，临时源文件未变。
- 看板容器健康接口与模板渲染通过，未配置的快捷入口隐藏。
- MySQL 初始化脚本的标识符校验、特殊字符密码编码和只读授权生成测试通过；没有对生产数据库执行 SQL。
- Git 跟踪文件的本机路径、私钥和运行数据扫描通过；与原部署敏感值比对未发现复制。

未在这套新 Compose 中运行真实照片清理，也未将其替换到原在线服务。MySQL 8.4 的真实初始化、手机授权和 Google 相册 UI 工作流仍需在目标部署环境做小批量验收。不能将源码测试和镜像构建理解为已完成生产迁移。

建议验收顺序：挂载和权限 → 数据库两个账号 → ADB 识别 → Syncthing 配对 → dry-run → 专用测试文件双向删除 → 小批真实备份 → 手机重启重连 → 宿主机重启恢复。验收时不要放宽源保护。
